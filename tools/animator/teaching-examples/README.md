# Teaching references

The manifest selects one reference by explanatory structure in frozen narration,
learning purposes and equations. Its terms include English, Portuguese and Spanish
examples. This is a deterministic heuristic, with a declared mechanism fallback;
it is not a semantic classifier. Manifest order resolves equal scores. The selected
style remains the authority for medium, typography, color and texture.

Each entry contains executable Canvas source, an annotated narration/visual
sequence, and three rendered representative frames. The four compact diagram
studies teach mechanisms, comparisons, algebra and procedures. Their deliberately
simple artwork demonstrates choreography and should be redrawn in the chosen style.

The network and institutional-change references use the latest locally saved Silk
Roads and Brazilian dictatorship animation sources available during this change.
Their JSON records retain source checksums and concrete improvement targets. They
demonstrate useful object continuity and provide material to improve, rather than
setting a ceiling on illustration quality. No account, session, voice or learner
data is bundled.

Regenerate frames offline from the checked-in sources:

```sh
node tools/animator/render-teaching-examples.mjs
```

The script uses isolated headless Chrome on macOS or Chromium on Linux; set
`CHROMIUM_PATH` for another executable. Inspect regenerated images before accepting
reference changes. Source, notes and image sizes are bounded when loading the
catalog. Older/custom tool packages without this catalog retain their style example.
