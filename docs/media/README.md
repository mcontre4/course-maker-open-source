- `home.png` and `create-lesson.png`: fresh screenshots of this source snapshot in browser demo mode, using a generic learner profile and no production data.
- `silk-roads.mp4`: a previously rendered Course Maker lesson, *How the Silk Roads connected cultures*, approximately 65 seconds.

Videos were selected from local generation outputs, transcoded to 720p H.264/AAC, stripped of source container metadata and chapters, and fully decoded for validation. Raw job inputs, model conversations, account details and internal artifact identifiers are excluded. These examples demonstrate generated output; they are not a guarantee of factual accuracy or output quality.
